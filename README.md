# Public game policy pages

This public repository hosts static privacy policies and terms pages for independently published mobile games. **It does not contain any game source code, signing keys, AdMob secrets, or private assets.**

## Snow Swarm

- [Snow Swarm Privacy Policy](snow-swarm/privacy.html)
- [Snow Swarm Terms of Use](snow-swarm/terms.html)

To make the HTML files publicly accessible as a website, enable **Settings → Pages → Deploy from a branch → main / (root)** on this repository. Until GitHub Pages is enabled, file links in the repository are *not* public webpage URLs suitable for the Google Play privacy field.

Only the game's actual behavior and the data collected by its current advertising SDK should be disclosed. See Google's current [Mobile Ads SDK data disclosure](https://developers.google.com/admob/android/privacy/play-data-disclosure).
